# Business Website

A responsive business website built with HTML, CSS, and JavaScript. It includes a main landing page for visitors and a separate `/admin` section for managing content.

**Live Site:** https://sandipbeghaa.github.io/Business-Website/

## What's Inside

- **Main Landing Page (`index.html`):** Includes a sticky navbar that changes color when you scroll, smooth section scrolling, and a team showcase.
- **Admin Section (`admin/`):** A separate page (`admin/index.html`) with its own JavaScript file (`admin/script.js`) to keep admin logic separated from the public site.
- **Responsive Layout (`style.css`):** Built using CSS Flexbox and custom gradients so it works on both laptops and phones.

## Built With

- HTML5
- CSS3
- Vanilla JavaScript

## How to Run It on Your Computer

1. Download or clone this repository:
   ```bash
   git clone https://github.com/sandipbeghaa/Business-Website
   ```
2. Open the `Business-Website` folder.
3. Double-click `index.html` to open it in your browser (or open it with Live Server in VS Code).

## What I Practiced & Learned

- Organizing a multi-page website so the public pages and admin files stay separate.
- Building a sticky navigation bar that reacts to scrolling without covering up section headings.
- Uploading a project from VS Code to GitHub and hosting it live with GitHub Pages.
